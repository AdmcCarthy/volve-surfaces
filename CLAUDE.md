# Volve Surfaces: working rules

Browser viewer of the Volve geophysical interpretations (horizons, faults, wells) as smoothed, shaded contour maps in D3.
Owner: Adam McCarthy. Plan: docs/plan.md.

@../../shared/idiom/CORE.md

Voice and structure of written work (README, docs) follow Idiom's CORE.md and house style: British English, impersonal, one creative headline then plain varied headings, a section ends on its last point. The line above is harmless when the file is absent (CI).

- Follow SubScout's styleguide and tokens (github.com/AdmcCarthy/SubScout) and Relief's palette and smoothing (github.com/AdmcCarthy/Relief). No raw hex in pages: use tokens.
- Volve terms: attribute Equinor and the former licence partners, link the terms, never sell, never imply endorsement, never present data misleadingly. Every map shows a "Generalised for display" badge with smoothing parameters and deviation.
- CRS of source: ED50 / UTM 31N (EPSG:23031). Horizon rows: IL, XL, UTMX, UTMY, Z.
- Ship quantised grids; contour in the browser (d3-contour). Plain ES modules + CSS, D3 pinned from cdnjs, no Node build.
- Python >= 3.12 via uv. `uv run pytest`, `uv run ruff check . && uv run ruff format .`. data/raw is git-ignored.
- British English, metric, sentence-case headings. Interpreted values carry confidence labels (Observed / Derived / Interpreted).
- Site (site/): plain ES modules, d3 7.9.0 from cdnjs. `css/subscout/` is copied unchanged from SubScout (see NOTICE.md); colours are read from its `--ss-data-seq-*` / `--ss-data-div-*` tokens at draw time. No raw hex in our own files (tests enforce it). `scripts/stage.py` builds `_site/` (site + data/real + data/synthetic); the Pages workflow runs the same script.
- Stepped fill = stacked d3-contour polygons on canvas; linear fill = per-pixel bilinear sample through a Lab ramp. Smoothing is a NaN-aware Gaussian (grid.js); every map states sigma and mean/largest change from the source.
- Editorial decisions (2026-11-08): **Fjord** is the chosen ramp. Detail levels are Raw, Light, Fine, Medium only (no Gaussian blur beyond about 50 m: broad smoothing was rejected as useless). Smoothing is edge-preserving (Perona-Malik, keeps fault steps); Light and above draw contours on a bicubic grid 2x denser. Class **step** (10, 20, 50, 100, or auto) plus adjustable **min and max**, not a class count. Contour intervals 10, 20, 50 (every fifth heavier). Shading light is placed across the measured fault trend (docs/fault-trend.md), fixed north-west as an option.
- The strongest colour is always the deepest: not an option. Default view: stepped fill with 10 m contour lines (agreed 2026-11-08). Shading uses one light per fault trend when two trends are about a quadrant apart.
- Architecture: docs/modules.md (modules, layer contract, normalised records, roadmap). Code layout: site/js/{surface,layers,host,style,vendor}; hydrocarbon contacts are documented in docs/contacts.md (the curated record is data/contacts/volve_curated.json, every number cited; rebuild with `PYTHONPATH=scripts uv run python -m adapters.volve.contacts <zip>`); adapters in scripts/adapters/<source>/ (run as `PYTHONPATH=scripts uv run python -m adapters.volve.faults <zip>`). Standards: docs/geostandard.md (Sodir Geostandard v22.00 review). Decisions 2026-11-08: well symbols live in **SubScout** (shape-first, colour optional); canonical CRS is **ETRS89 / UTM 31N (EPSG:25831)**, converted in adapters, never in layers; the Geostandard is the authority for map-type names, title-box fields, symbols and standard colours, SubScout style guide for the rest. ED50 to ETRS89 at Volve is about -90 m E, -215 m N (not 100 m); always convert through scripts/crs.py. Vertical datum is mean sea level, positive down (verified, docs/datum-check.md). Before pushing changes to site/: `uv run python scripts/stage.py && uv run --with playwright python scripts/smoke.py` (needs Edge or Chrome; 0 console errors, canvases painted).
- Ownership: this repo owns contour-based subsurface interpretation display (surfaces, faults, barriers, contact lines and fills, and their line styles); SubScout owns tokens and point symbols. Contacts: the model outline is an accepted, labelled trap limit; the Geostandard colour and contact-line preset exists, off by default, never the default because it is not colour-vision safe.
- Map furniture (2026-11-08): scale bar and north arrow are drawn on the canvas (`host/furniture.js`, so exports carry them); the title box (`host/titlebox.js`) follows the Geostandard's field names and order as a guide, not a rule, with rows built from the manifest and layers; the location map uses Relief's north_sea overview layers and Detuned palette (`data/context/`, `vendor/relief/`, built by `scripts/context.py`; Copernicus and EMODnet attribution travels with it) plus Wildcat's Sodir field outlines, in Relief's CRS (EPSG:25832), real data only. Rings are drawn planar by hand, not with d3.geoPath (unwound rings read as the sphere's complement). PNG export is `host/export.js`.
- Structure analysis (2026-11-08, docs/contacts-structure.md): `scripts/structure.py` builds `closures.json` (merge tree: highs, relief, spill points, edge spills) and fault `attrs` (throw, thickness, ratio, length, strike) and well `surface_connection`; run it after the adapters. **Fault seal analysis is out of scope**: any fault, however small, may be a barrier; attrs are measurements and the throw/thickness ratio is a juxtaposition indicator only, never a seal call or a minor/major class. The Volve default fill stays the provided outline and barrier; the closure layer and the tentative tier are switch-on analysis. Not built, by decision: the area-depth chart and the robustness gates.
- **Scope (2026-11-08): the base case is rendering surfaces from seismic interpretations** (horizons, fills, contours, shading, faults, furniture, export). Hydrocarbon contacts, closure polygons, the tentative fill and the area-depth charts are **work in progress and paused**: kept, switched off by default, shown only on `wip.html` and under the viewer's collapsed *Work in progress* group, and never in the base examples, README headline or options page. Do not extend them without being asked.
