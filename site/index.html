How should the Volve surfaces look?

Every map below is the same horizon, the top of the Hugin Formation in depth, drawn with a different treatment. Colours come straight from SubScout's tokens, in light and dark. Nothing is hard-coded here, so a change to the palette in SubScout changes these maps.

What to decide
  1. Linear gradient or stepped classes as the default fill (Fjord is chosen).
  2. The default detail level: Raw, Light, Fine or Medium.
  3. The default class step and how the colour range is set (data range rounded to the step, or by hand).
  4. The default contour interval: none, 10, 20 or 50 m.
  5. Shading: strength, and whether the light is placed across the fault trend or fixed north-west.

The ramps

Sequential ramps (seven steps) for depth and thickness, and diverging ramps (nine steps) for residuals. Steps are read from the live tokens; the stepped fills use them directly, the linear fills blend between them in Lab.
